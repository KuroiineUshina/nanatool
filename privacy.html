나나툴 개인정보처리방침

시행일 2026년 8월 24일 · 적용 버전 1.0.0

나나툴은 디시인사이드에서 동작하는 브라우저 확장프로그램입니다. 개발자 서버, 사용자 계정, 광고, 분석 도구, 추적 도구 또는 클라우드 동기화를 사용하지 않습니다.

처리하는 정보

  • 유동 필터, 테마, 플로팅 버블 위치·크기·사용자 지정 이미지
  • 갤러리별 말머리 필터, 글쓰기 기본 말머리, 머리말·꼬리말
  • 게시물·이미지 북마크의 주소, 제목, 폴더, 메모와 파일 정보
  • 강조할 등록 사용자 식별 코드와 선택적 표시 이름
  • 사용자가 활동 명함을 만들 때 요청한 공개 갤로그 통계와 운영 갤러리 정보
  • GitHub 최신 정식 릴리스의 버전·주소와 마지막 확인 시각

나나툴은 비밀번호를 입력받거나 저장하지 않습니다. 로그인 상태가 필요한 기능은 브라우저에 이미 설정된 디시인사이드 세션을 사용하며, 원시 쿠키나 인증 토큰을 읽어 저장하지 않습니다.

이용 목적

위 정보는 디시인사이드 표시 정리, 글쓰기 보조, 로컬 북마크, 작성자 강조, 사용자가 요청한 활동 명함 생성이라는 확장프로그램 기능 제공에만 사용합니다.

외부 통신

나나툴은 현재 디시 페이지에 기능을 적용하거나, 사용자가 이미지 북마크·활동 명함·글 또는 댓글 등록 기능을 직접 사용할 때 HTTPS 디시인사이드 도메인과 통신합니다. 또한 30분 주기 또는 나나툴 화면을 열 때 GitHub 공개 API에서 최신 정식 릴리스 버전을 확인합니다. GitHub 요청에는 계정·쿠키·인증 토큰·북마크·사용자 설정을 넣지 않으며 자동 다운로드·설치하지 않습니다. 일반적인 HTTPS 통신 과정에서 IP 주소와 브라우저 요청 정보는 GitHub가 처리할 수 있습니다.

확장프로그램에 저장된 사용자 데이터는 개발자 서버, 광고·분석 사업자에게 전송하거나 판매하지 않습니다.

활동 명함을 게시글에 등록하면 그 시점의 명함 내용은 해당 게시글을 열람할 수 있는 사람에게 공개되며 자동 갱신되지 않습니다.

저장 위치와 보관 기간

  • 설정과 북마크 메타데이터는 chrome.storage.local에 저장됩니다.
  • 이미지 북마크 원본은 확장프로그램 전용 Cache Storage에 저장됩니다.
  • 활동 명함용 정보는 현재 디시 페이지 메모리에 최대 5분 동안만 보관됩니다.
  • 최신 릴리스 버전·주소·확인 시각과 조건부 요청용 ETag는 chrome.storage.local에 저장됩니다.
  • 이미지는 한 장당 최대 30MB, 최대 500개, 전체 최대 1GB로 제한됩니다.

북마크를 삭제하면 해당 로컬 데이터가 삭제됩니다. 확장프로그램을 제거하면 브라우저가 확장프로그램 전용 저장소를 제거합니다.

권한 사용

  • storage: 설정, 북마크, 폴더와 강조 대상의 로컬 저장
  • unlimitedStorage: 사용자가 저장한 이미지 북마크의 누락 방지
  • declarativeNetRequestWithHostAccess: 디시 이미지 요청에 필요한 요청 헤더의 선언적 적용
  • alarms: 30분 주기의 릴리스 확인 일정 유지
  • 디시인사이드 호스트 접근: 필터·작성 보조·북마크·활동 명함 기능 제공
  • api.github.com 호스트 접근: 최신 공개 정식 릴리스 메타데이터 확인

보안

원격 코드를 내려받아 실행하지 않습니다. 실행 코드는 확장프로그램 패키지 안에 포함되며, 외부 주소와 리디렉션은 허용된 HTTPS 디시인사이드 주소인지 다시 확인합니다. 업데이트 링크도 지정된 나나툴 GitHub Releases 경로인지 확인합니다. 저장 이미지와 네트워크 응답의 크기·개수를 제한합니다.

사용자의 선택과 삭제

전체 설정에서 저장한 규칙·북마크·폴더·강조 대상을 수정하거나 삭제할 수 있습니다. 이미지 북마크를 해제하면 해당 이미지 파일도 삭제됩니다. 모든 데이터를 한 번에 삭제하려면 브라우저에서 나나툴을 제거할 수 있습니다.

데이터 사용 원칙

나나툴이 처리하는 사용자 데이터는 확장프로그램의 사용자 대상 기능을 제공하는 용도로만 사용합니다. 개발자 서버나 제3자에게 전송해 광고·분석·프로파일링에 사용하지 않습니다.
