# 나나툴 (Nana Tool)

디시인사이드 PC 갤러리용 Chrome/Edge Manifest V3 확장프로그램입니다.

## 기능

- 사용자가 저장한 글 꼬리말 템플릿으로 표시하는 디시 활동 명함
  - 템플릿의 `{{갤로그ID}}`, `{{갤로그주소}}`, `{{닉네임}}` 토큰을 현재 로그인 사용자의 값으로 치환
  - 나나툴 본체는 사진을 수집하거나 업로드하지 않고 저장된 꼬리말과 활동 정보 토큰만 처리
  - 디시가 `flex`를 제거해도 통계가 무너지지 않는 `table` 기반 게시용 레이아웃
  - 116px 원형 갤로그 프로필을 왼쪽에 두고 오른쪽에 닉네임·글·댓글·글댓비·방문 수를 표시하는 투명 배경 디자인
  - 갤로그의 게시글·댓글 수와 글 1개당 댓글 수(`1 : n`) 자동 계산
  - 오늘 방문자와 누적 방문자 표시
  - 운영 중인 마이너·미니·인물 갤러리를 주딱·파딱으로 구분
  - 디시의 매니저·부매니저 아이콘을 사용한 클릭형 갤러리 뱃지
  - 제공된 HTML/CSS 템플릿을 기존 글 꼬리말 칸에 붙여넣으면 등록 시점의 정보를 자동 치환
  - 통계와 운영 목록은 디시인사이드 페이지에서만 직접 읽고 현재 페이지 메모리에 최대 5분 보관
  - 오른쪽 로그인 상자에 갤로그 링크가 없는 글쓰기 화면에서도 공식 헤더 식별 영역과 인증된 내 갤로그 주소로 계정을 자동 확인
  - 기본 통계가 준비되면 즉시 등록 가능하며, 역할이 불명확한 운영 갤러리의 주딱·파딱 확인은 제출을 막지 않고 뒤에서 처리
- 팝업·페이지 내 도구는 Liquid Glass, 전체 설정은 간격을 둔 플랫 UI로 구성
- 버블 메뉴는 현재 디시인사이드 페이지의 라이트·다크 설정을 그대로 따르고, 갤러리아·전체 설정은 공통 테마를 사용
- GitHub 정식 릴리스를 주기적으로 확인하고 새 버전이 있을 때만 수동 업데이트 버튼과 툴바 `UP` 배지 표시
  - 자동 다운로드·설치·재시작 없이 해당 GitHub Release 페이지를 새 탭으로 열기
  - 30분 주기와 나나툴 화면을 열 때 확인하며, GitHub 조건부 요청과 요청 제한 재시도 시간을 준수
- 전체 설정에서 버블 크기를 40~120px로 조절하고, 이미지를 드래그·확대해 원형 프레임에 맞춘 뒤 적용하거나 제거
- 유동 작성 게시물과 댓글을 각각 숨김
  - `data-ip`가 있고 등록 식별 코드가 없는 작성자만 유동으로 판정
  - 정보가 없거나 서로 충돌하면 숨기지 않는 fail-open 방식
- 갤러리별 게시판 말머리 필터
  - `전체 보기`, `선택한 말머리만 보기`, `선택한 말머리 숨기기`
  - 말머리 탭 오른쪽 설정 아이콘에서 체크박스로 복수 선택
  - 현재 글 목록에 없는 말머리도 탭과 접힌 메뉴에서 함께 수집
  - 정식·마이너·미니·인물 갤러리를 서로 다른 설정으로 구분
- 갤러리별 글쓰기 말머리 자동 선택
  - 목록에서 보고 있던 말머리를 같은 탭의 글쓰기 화면에 우선 적용
  - 현재 말머리가 없거나 글쓰기에서 사용할 수 없으면 지정한 기본 말머리 적용
  - 현재 말머리 우선 사용 여부와 기본 말머리를 말머리 설정창에서 바로 변경
  - 화면 가장자리 버블 메뉴에서도 현재 갤러리의 두 옵션을 바로 변경
- 갤러리별 작성 문구
  - 글 머리말
  - 글 꼬리말
  - 댓글·답글 꼬리말
  - 글 머리말·꼬리말별 선택 색상과 안전한 인라인 CSS 선언
  - 글 꼬리말에 붙여넣은 안전한 HTML/CSS 템플릿과 활동 통계 토큰 지원
  - 정식·마이너·미니·인물 갤러리를 서로 다른 설정으로 구분
- 글 보기 본문 위에도 `수정`·`삭제` 버튼 표시
  - 하단 원본 버튼이 실제로 있는 경우에만 표시
  - 클릭 시 사이트의 원본 버튼 동작에 위임
- 로컬 북마크
  - 폴더 생성, 이름 변경, 삭제
  - 전체 설정에서 북마크를 폴더에 드래그 앤 드롭해 이동
  - 북마크 삭제
  - 북마크별 메모
- 이미지 북마크와 `갤러리아`
  - 게시물 본문 이미지 아래의 `이미지 북마크` 버튼으로 글 북마크와 별도 저장
  - 이미지 원본 바이트는 확장프로그램 전용 로컬 Cache Storage에, 제목·원문·폴더 정보는 `chrome.storage.local`에 저장
  - 같은 디시 이미지 주소는 한 번만 저장하고, 북마크 해제 시 로컬 이미지 파일도 함께 삭제
  - 이미지 폴더 생성, 이름 변경, 삭제와 드래그 앤 드롭 이동
  - 폴더 이름 왼쪽의 눈 아이콘으로 `모든 이미지` 목록에서 해당 폴더 썸네일 흐림 여부 전환
  - 썸네일 표시 상태에는 MIT 라이선스의 Bootstrap Icons `eye`·`eye-slash` 사용 (`THIRD_PARTY_NOTICES.md` 참조)
  - 버블 메뉴의 `갤러리아`에서 폴더별 썸네일, 검색, 확대 보기, 원문 이동 지원
  - 확대 보기에서 키보드 `←`·`→`로 현재 폴더·검색 결과의 이전/다음 이미지 이동
  - 방향키 이동 시 좌우 슬라이드 전환 애니메이션, 썸네일·확대 보기의 이미지 이름 비표시
  - PNG·APNG·JPEG·WebP·GIF·AVIF·BMP·ICO와 실행 요소가 없는 안전한 SVG, 한 장당 최대 30MB 지원
  - 원본 링크, `srcset`, 지연 로딩 속성과 확장자 없는 디시 CDN 주소에서 실제 표시 원본 탐색
- 지정한 반고닉·고닉 닉네임 강조
  - 등록 식별 코드로만 정확히 일치
  - 닉네임은 표시용이며 일치 조건으로 사용하지 않음
  - 글 목록이나 본문 상단 전체가 아닌 닉네임 부분에만 강조색 적용
- 화면 좌우에 붙는 플로팅 버블
  - 기본 상태는 투명한 Liquid Glass이며, 전체 설정에서 사용자 이미지를 선택하면 원형으로 표시
  - 클릭하면 기존 나나툴 팝업 기능을 페이지 안에서 열기
  - 드래그 종료 시 가까운 좌우 가장자리로 부드럽게 스냅
  - 좌우와 세로 위치를 로컬에 저장

## GitHub Releases 설치

1. [최신 GitHub Release](https://github.com/KuroiineUshina/nanatool/releases/latest)에서 `nanatool-v1.0.0.zip`을 내려받습니다.
2. ZIP을 원하는 위치에 압축 해제합니다.
3. Chrome의 `chrome://extensions` 또는 Edge의 `edge://extensions`를 엽니다.
4. 개발자 모드를 켭니다.
5. `압축해제된 확장 프로그램을 로드`하고 압축을 푼 폴더를 선택합니다.

GitHub ZIP 배포판은 개발자 모드의 압축 해제 설치 방식이므로 자동 업데이트되지 않습니다. 새 릴리스가 확인되면 나나툴 화면의 `업데이트 v…` 버튼이나 툴바 `UP` 배지가 나타납니다. 버튼은 GitHub Release 페이지를 열기만 하며, ZIP은 사용자가 직접 내려받아 같은 폴더에 덮어쓴 뒤 확장프로그램 카드의 새로고침 버튼을 눌러야 합니다. 함께 제공되는 `.sha256` 파일로 ZIP의 SHA-256도 확인할 수 있습니다.

## 소스 폴더에서 설치

1. Chrome의 `chrome://extensions` 또는 Edge의 `edge://extensions`를 엽니다.
2. 개발자 모드를 켭니다.
3. `압축해제된 확장 프로그램을 로드`를 선택합니다.
4. 이 `dcinside-focus` 폴더를 선택합니다.
5. 이미 설치한 상태라면 확장프로그램 카드의 새로고침 버튼을 누릅니다.

## 사용

- 글쓰기·수정 화면에서 첨부 이미지의 `webp-mp4`·`gif-mp4` 클래스를 자동으로 제거합니다. HTML 편집 모드에서는 등록 직전에 처리하며, 다른 클래스와 이미지 주소·첨부 정보는 유지합니다. 원본 움짤 재생을 위한 보조 기능으로, 서버에서 이미 변환된 파일의 프레임을 복원하지는 않습니다. 실제 재생 개선 여부는 게시 후 확인이 필요합니다.
- 기존에 글 꼬리말로 저장한 활동 명함 HTML·CSS는 계속 사용할 수 있으며, 나나툴은 `{{게시글수}}`, `{{댓글수}}`, `{{글댓비}}` 같은 토큰만 실제 값으로 바꿉니다.
- 명함의 HTML·CSS와 운영 갤러리 항목 구조는 저장된 글 꼬리말 코드가 원본입니다. `{{갤로그프로필이미지}}`는 공개 갤로그 이미지 URL로만 치환하며, 나나툴은 사진을 첨부 파일로 만들거나 업로드하지 않습니다.
- `글댓비 1 : n`은 게시글 1개당 작성한 댓글 수입니다. 명함에 삽입된 운영 갤러리 뱃지를 누르면 해당 갤러리로 이동합니다.
- 명함 숫자는 글 작성 화면에서 활동 정보를 읽은 시점의 스냅샷입니다. 공개 갤로그 사진 URL은 디시의 게시 처리·캐시 정책에 따라 게시물에서 유지되지 않을 수 있으며, 나나툴은 이를 우회해 자동 업로드하지 않습니다.
- 갤러리 목록의 말머리 탭 오른쪽 `⚙`을 누르고, 말머리를 체크한 다음 `보기 / 안 보기` 스위치를 고릅니다. 변경은 바로 저장됩니다.
- 같은 설정창의 `글쓰기 말머리`에서 `보고 있던 말머리 우선`과 갤러리별 `기본 말머리`를 정합니다. 우선순위는 현재 보고 있던 말머리 → 기본 말머리 → 디시 사이트 기본값입니다.
- `선택한 말머리만 보기`는 선택하지 않은 일반 목록 행을 숨기고, `선택한 말머리 숨기기`는 선택한 일반 목록 행만 숨깁니다.
- 전체 설정의 `갤러리별 머리말·꼬리말`에서 주소의 `id`와 갤러리 종류를 등록합니다.
- 글 머리말·꼬리말은 색상 적용을 켜거나 `font-size: 18px; text-align: center` 같은 인라인 CSS 선언을 추가할 수 있습니다. 외부 URL과 페이지 배치를 침범하는 선언은 저장할 때 제거됩니다.
- 댓글 꼬리말은 디시의 일반 텍스트 댓글 입력 방식을 따르므로 색상과 CSS를 지원하지 않습니다.
- 글과 댓글 문구는 사이트가 제출값을 읽기 직전에 붙입니다. 활동 정보가 아직 준비되지 않았으면 해당 등록을 중단하고 준비 완료 안내를 표시하며, 사용자가 등록 버튼을 다시 눌러야 합니다. 나나툴이 등록 동작을 자동 재실행하지 않습니다.
- 게시물 보기 페이지의 `나나툴 북마크`는 기본 폴더에 저장합니다. 팝업과 전체 설정에서 폴더·메모를 편집할 수 있습니다.
- 게시물 본문 이미지 아래의 `이미지 북마크`는 이미지 원본을 이 브라우저에 저장합니다. 버블 메뉴의 `갤러리아`에서 폴더별로 정리하거나 삭제할 수 있습니다.
- 이미지 북마크를 해제하면 해당 이미지의 로컬 파일도 즉시 삭제됩니다. 확장프로그램 제거 시 이미지 보관함 전체가 함께 삭제됩니다.
- 전체 설정의 북마크 제목 영역을 왼쪽 폴더에 끌어다 놓으면 곧바로 해당 폴더로 이동합니다.
- 화면 가장자리의 투명한 글래스 버블을 누르면 빠른 설정이 열립니다. 빠른 설정의 테마는 현재 디시 페이지와 자동으로 동기화됩니다. 버블을 드래그하면 놓은 높이를 유지한 채 가까운 왼쪽 또는 오른쪽 가장자리에 붙습니다.
- 전체 설정과 갤러리아 상단의 이동 버튼으로 두 화면을 왕복할 수 있습니다.
- 새 버전 알림은 GitHub의 최신 정식 릴리스 버전이 현재 manifest 버전보다 높을 때만 표시됩니다. 프리릴리스는 알리지 않으며 자동으로 설치하지 않습니다.

## 판별·동작 기준

- 게시물 목록: 검증된 목록 컨테이너와 작성자 속성. 본문 아래 목록은 숫자 글번호와 실제 글 링크가 모두 있는 행만 포함
- 게시판 말머리: 목록 행 안의 `.gall_subject` 또는 검증된 말머리 속성
- 댓글: 댓글 영역 안의 개별 댓글 컨테이너
- 글 본문: 게시물 보기 화면에 `.writing_view_box`가 정확히 하나일 때만
- 글 수정·삭제: 본문 아래에 활성 원본 버튼이 실제로 있을 때만
- 글 작성: `form[name="write"][action*="article_submit"]` 안의 Summernote 편집 영역과 `memo` 제출 필드가 함께 있을 때만
- 댓글 작성: 댓글 영역 안에서 클릭한 등록 컨트롤과 같은 입력기의 `textarea`만

사이트 DOM이 달라져 대상을 확정할 수 없으면 해당 기능만 적용하지 않습니다.

## 글꼴

- 모든 나나툴 UI는 한국어 기본판 Pretendard를 우선 사용합니다.
- 로컬 Pretendard Regular·Medium·SemiBold를 굵기별로 연결하며, 설치되지 않은 환경에서는 시스템 sans-serif 글꼴로 대체됩니다.

## 릴리스

- `powershell -ExecutionPolicy Bypass -File scripts/build-release.ps1`로 설치 ZIP과 같은 이름의 SHA-256 체크섬 파일을 만듭니다.
- `powershell -ExecutionPolicy Bypass -File scripts/verify-release.ps1`로 ZIP 경로, 필수 파일, manifest 아이콘·버전과 SHA-256을 다시 검증합니다.
- 빌드 스크립트는 아이콘 PNG 규격을 검증하고, 최종 ZIP의 manifest에 16·32·48·128px 아이콘 경로를 자동 삽입합니다.
- `v1.0.0`처럼 manifest 버전과 일치하는 태그를 푸시하면 GitHub Actions가 테스트, ZIP·체크섬 생성, GitHub Release 등록을 수행합니다.
- 일반 Windows·macOS Chrome에서는 GitHub의 CRX를 직접 설치할 수 없으므로 릴리스 ZIP을 압축 해제해 개발자 모드로 로드합니다.
- 공개 전 수동 확인 항목은 `GITHUB_RELEASE_CHECKLIST.md`에 정리했습니다.

## 라이선스

현재 나나툴 본체에는 별도 오픈소스 라이선스가 부여되지 않았습니다. 공개 GitHub 저장소에서 소스를 열람하고 릴리스 ZIP을 설치할 수 있다는 사실이 코드·이미지의 재배포나 2차 이용 허락을 뜻하지는 않습니다. 오픈소스로 배포하려면 공개 전에 별도의 `LICENSE`를 선택해야 합니다. Bootstrap Icons의 MIT 고지는 `THIRD_PARTY_NOTICES.md`에 유지됩니다.

`tests/dom-fixture.html`을 브라우저에서 열면 작성자 판별, UID 강조, 갤러리 키, 말머리 포함·제외, 문구 중복 방지와 상단 버튼 위임을 확인할 수 있습니다.
