# 나나툴 자산

`pretendard-local.css`는 설치된 한국어 기본판 Pretendard Regular·Medium·SemiBold를 굵기별로 연결합니다.

`profile-card-image.js`는 활동 명함의 선택적 이미지 토큰에 사용하는 경량 PNG 자산입니다. 공개 배포 시 개인 캐릭터 이미지를 포함하지 않도록 나나툴의 여우·공구 아이콘을 사용합니다.

`icons/nanatool-icons.json`은 사용자가 제공한 이미지의 얼굴 영역을 원형으로 크롭한 빌드 전용 PNG 데이터입니다. `scripts/build-release.ps1`가 16·32·48·128px PNG를 GitHub Release용 ZIP 안에 생성합니다.

`store/nanatool-store-assets.json`은 이전 Chrome 웹 스토어 준비 과정의 로컬 보관 자료입니다. 현재 GitHub Release 빌드와 저장소 배포 대상에는 포함하지 않습니다.

`bootstrap-eye.svg`와 `bootstrap-eye-slash.svg`는 갤러리아 폴더의 썸네일 표시 상태에 사용하는 MIT 라이선스 아이콘입니다.
